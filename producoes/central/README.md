# Central dos Canais

Página publicada: https://claude.ai/artifact/UZ3YFHzLpBjiJj3Mskzj1q

Organiza os vídeos do **Lado Sombrio do Universo** e do **Inquérito Sombrio**: status, data de publicação, plataformas onde já saiu, o vídeo (Shorts até 20 MB) e as legendas prontas para YouTube, TikTok e Reels, com botão de copiar.

- `central.html`: código da página (banco de dados `videos` + arquivos anexados).
- `extrai.py` / `seed.py`: importaram as legendas dos documentos dos dois repositórios para o banco (carga inicial).
- Vídeos longos passam do limite de 20 MB por arquivo: use o campo "Link do arquivo do vídeo".
